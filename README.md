## DeskBot  
A small desktop robot that I am building from scratch, step by step.  
I start with a very simple, cheap version and keep upgrading it:  
sensing, movement, speech, and later AI.  
   
## Current status  
Version V0, Phase 1, Week 1.  
Daily progress is in docs/journal.md  
   
## Hardware  
- Brain: ESP32  
- Drive plan: 2 wheels + 1 caster wheel  
- Design software: Fusion 360  
   
## Folders  
- firmware/   code that runs on the robot  
- hardware/   3D designs and wiring diagrams  
- docs/       journal, notes and photos  
- tests/      small programs to test one part at a time  
##    
## Goal  
Learn robotics and embedded systems by building the same robot over time.  
Every version must work before I start the next one.
